# EENOS Product Delivery

This repository is the shared, version-controlled operating workspace for managing the roadmap, delivery, documentation, interface evolution, AI role definitions, and repository governance of EENOS.

## Start here

1. Read `000-standards/repository-map.md`.
2. Read `100-governance/repository-governance/001-Repository-Architecture.md`.
3. Work only in folders allowed by your role specification.
4. Do not create or rename folders. Submit a repository change request under `600-repository/change-requests/`.
